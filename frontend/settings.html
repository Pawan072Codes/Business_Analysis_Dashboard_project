⚙️

Google OAuth Setup Required

The system administrator must configure Google OAuth 2.0 Client credentials in the backend environment.

1. In Google Cloud Console, create OAuth 2.0 Web Client.
2. Add Authorized Redirect URI: http://127.0.0.1:8000/api/gmail/callback
3. Add to backend .env:
  GOOGLE_CLIENT_ID=your_client_id.apps.googleusercontent.com
  GOOGLE_CLIENT_SECRET=your_client_secret
🛡️
Multi-User Security & Token Privacy Guarantee
• Isolated Senders: User A sends exclusively from User A's connected Gmail; User B sends from User B's.
• Encryption at Rest: Access and refresh tokens are encrypted using AES-128-CBC/Fernet with server-side keys before writing to PostgreSQL.
• Strict Scope: Only https://www.googleapis.com/auth/gmail.send is granted. BizVision cannot read your inbox or delete emails.
